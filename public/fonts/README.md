# Font sources

Clash Display variable (200-700) and Satoshi variable (300-900): Indian Type Foundry, obtained from the official Fontshare API on 2026-10-08. Usage is subject to the Fontshare ITF Free Font License: https://www.fontshare.com/licenses/itf-ffl

Geist Mono Latin variable: @fontsource-variable/geist-mono, Vercel, SIL Open Font License 1.1. Its license is included alongside the font.

All WOFF2 files are served locally with next/font/local. The saved fontshare.css is source provenance only and is not imported by the app.
